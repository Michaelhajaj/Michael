# הפעלת הדמיית ה-AI על תמונה

מתכנן התקרה (`planner.html`) עובד גם בלי השלב הזה: הוא מייצר הדמיה סכמטית ותוכנית תקרה.
אחרי שמשלימים את השלבים כאן, לקוח שמעלה תמונה של החדר יקבל הדמיה של התקרה **על התמונה שלו**.

## למה צריך את זה
ההדמיה נוצרת על ידי מודל AI בתשלום (OpenAI). אסור לשים את מפתח הגישה בתוך האתר,
כי כל אחד יכול לראות את הקוד שלו. לכן המפתח נשמר בשרת קטן וחינמי ב-Cloudflare,
והאתר פונה אליו.

## עלות
בערך $0.04–$0.07 להדמיה באיכות `medium` (15–25 אגורות). מומלץ להגדיר תקרת הוצאה
חודשית בחשבון OpenAI (Settings → Limits), למשל $10.

## שלבים (פעם אחת, כ-15 דקות)
1. **OpenAI:** פותחים חשבון ב-platform.openai.com, מוסיפים אמצעי תשלום, יוצרים API key.
   ייתכן שתתבקש אימות ארגון כדי להשתמש במודל התמונות.
2. **Cloudflare:** פותחים חשבון חינמי ב-dash.cloudflare.com → Workers & Pages → Create → Worker.
3. מדביקים את כל התוכן של `worker.js` במקום הקוד הקיים ולוחצים Deploy.
4. ב-Settings → Variables and Secrets מוסיפים:
   - `OPENAI_API_KEY` (מסוג Secret): המפתח מ-OpenAI
   - `ALLOWED_ORIGINS`: `https://michaelhajaj.github.io` (ואם יהיה דומיין, מוסיפים אותו בפסיק)
5. מעתיקים את כתובת ה-Worker (משהו כמו `https://ceiling-ai.xxxx.workers.dev`)
   ומדביקים אותה ב-`js/config.js`:
   ```js
   aiEndpoint: "https://ceiling-ai.xxxx.workers.dev"
   ```

זהו. מעכשיו מי שמעלה תמונה במתכנן התקרה מקבל הדמיית AI.
