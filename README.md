# אתר עבודות גבס

אתר תדמית מקצועי לעבודות גבס – בעברית, מותאם לנייד, עם גלריית עבודות וטופס פנייה שנשלח ישירות לוואטסאפ.

## מבנה

```
index.html          ← דף האתר
css/style.css       ← עיצוב
js/config.js        ← ★ הפרטים שלך + רשימת העבודות (הקובץ היחיד שצריך לערוך)
js/main.js          ← לוגיקה (גלריה, טופס, תפריט)
images/works/       ← ★ כאן שמים תמונות של עבודות
images/hero.svg     ← תמונת הרקע הראשית (אפשר להחליף בתמונה אמיתית)
images/about.svg    ← התמונה באזור "אודות"
```

## 1. עדכון הפרטים שלך

פתח את `js/config.js` ושנה: שם העסק, טלפון, מספר וואטסאפ (בפורמט `9725XXXXXXXX`), אזור שירות, שנות ניסיון ועוד.

## 2. העלאת עבודה חדשה לגלריה

1. העלה את התמונה לתיקייה `images/works` (למשל `salon-ramat-gan.jpg`).
   מומלץ תמונה לרוחב, עד כ־1600 פיקסלים רוחב.
2. ב־`js/config.js` הוסף שורה לרשימת `WORKS`:

```js
{ image: "images/works/salon-ramat-gan.jpg", title: "תקרה צפה בסלון", category: "תקרות", location: "רמת גן" },
```

כפתורי הסינון בגלריה נוצרים אוטומטית לפי הקטגוריות.
את העבודות לדוגמה (`sample-1.svg` … `sample-6.svg`) כדאי למחוק מהרשימה כשיש לך תמונות אמיתיות.

> אפשר לעשות את כל זה ישירות מאתר GitHub: נכנסים לתיקייה `images/works` → **Add file → Upload files**, ואז עורכים את `js/config.js` עם כפתור העיפרון.

## 3. העלאה לאוויר (חינם) עם GitHub Pages

1. ב־GitHub: **Settings → Pages**
2. ב־Source בחר את הענף (branch) ואת התיקייה `/ (root)` ← **Save**
3. אחרי דקה־שתיים האתר יהיה זמין בכתובת `https://<שם-המשתמש>.github.io/<שם-הריפו>/`

אפשר לחבר דומיין משלך (למשל `gevesmichael.co.il`) באותו מסך.

## איך פונים אליך

- כפתור וואטסאפ צף בכל עמוד
- טופס "הצעת מחיר" – הלקוח ממלא פרטים, והם נפתחים אצלו כהודעת וואטסאפ מוכנה אליך
- קישור חיוג ישיר לטלפון
