# Michael Hajaj – עבודות גבס וצבעים דקורטיביים

אתר תדמית מקצועי לעבודות גבס – בעברית, מותאם לנייד, עם גלריית עבודות וטופס פנייה שנשלח ישירות לוואטסאפ.

## מבנה

```
index.html          ← דף האתר
css/style.css       ← עיצוב
js/config.js        ← ★ הפרטים שלך + רשימת העבודות (הקובץ היחיד שצריך לערוך)
js/main.js          ← לוגיקה (גלריה, טופס, תפריט)
images/works/       ← ★ כאן שמים תמונות של עבודות
images/hero.svg     ← תמונת הרקע הראשית (אפשר להחליף בתמונה אמיתית)
images/about.svg    ← התמונה באזור "אודות"
```

## 1. עדכון הפרטים שלך

פתח את `js/config.js` ושנה: שם העסק, טלפון, מספר וואטסאפ (בפורמט `9725XXXXXXXX`), אזור שירות, שנות ניסיון ועוד.

## 2. העלאת עבודה חדשה לגלריה

1. העלה את התמונה לתיקייה `images/works`.
2. ב־`js/config.js` הוסף שורה לרשימת `WORKS`:

```js
{ image: "images/works/salon.jpg", title: "תקרה צפה בסלון", category: "תקרות", location: "אשדוד" },
```

- כמה תמונות לאותו פרויקט: `images: ["a.jpg", "b.jpg"]` במקום `image`
- השוואת לפני/אחרי: מוסיפים `before: "images/works/before.jpg"`
- העבודה הראשונה ברשימה מוצגת כ"פרויקט נבחר"
- הגלריה מסדרת את הגדלים לבד, וכפתורי הסינון נוצרים לפי הקטגוריות

## 3. העלאה לאוויר (חינם) עם GitHub Pages

1. ב־GitHub: **Settings → Pages**
2. ב־Source בחר את הענף (branch) ואת התיקייה `/ (root)` ← **Save**
3. אחרי דקה־שתיים האתר יהיה זמין בכתובת `https://<שם-המשתמש>.github.io/<שם-הריפו>/`

אפשר לחבר דומיין משלך (למשל `gevesmichael.co.il`) באותו מסך.

- קישור חיוג ישיר לטלפון

## מתכנן התקרה (`planner.html`)

הלקוח מכניס מידות, בוחר סגנון ותאורה, ומקבל הדמיה, תוכנית תקרה וחתך עם מידות (אפשר להוריד או להדפיס), וכפתור לשליחת הסיכום בוואטסאפ.
כדי להפעיל הדמיית AI על תמונה של הלקוח, ראו `ai-worker/README.md`.

## מתכנן הגבס החכם (`plans.html`) – בתשלום

מעלים תוכנית אדריכלית (PDF / תמונה), מכיילים קנה מידה, ומסמנים תקרות, מחיצות, חיפויים, ספוטים, רמקולים, שקעים ודלתות.
המערכת מחשבת לפי ת״י 1924:
- **תקרות:** שתי וערב F47 / C60, משניים כל ≤500 / 550 / 406 לפי עובי הלוח וחדר רטוב, ראשיים כל ≤1000, מתלים כל ≤1000 (הראשון ≤400 מהקיר) עם בדיקת עומס ≤200 ניוטון. הפרופילים עוקפים אביזרים, ופתחים גדולים מקבלים חילוף ומתלים נוספים.
- **מחיצות:** ניצבים 50 / 70 / 100, בדיקת גובה מקסימלי (טבלה 1), ניצבים כל ≤600 (או ≤406 ברטוב / אריחים), תפרים מוסטים בין הצדדים, תפרים ≥15 ס״מ מפינות פתחים, ניצבים מחוזקים לדלתות, ופיזור שעוקף קופסאות חשמל.
- **כתב כמויות:** לוחות (כולל אופטימיזציית חיתוך), פרופילים, מסילות, מתלים, ברגים, עיגונים, סרט, מרק, בידוד ופינות.
- **השוואת אפשרויות**, שינוי חופשי של כל פרמטר, ו**הדמיית תלת-ממד** (כולל מצב "רנטגן" שמראה את השלד).

קבצים: `js/gypsum-rules.js` (ערכי התקן ונתוני חומרים, כאן מעדכנים), `js/gypsum-engine.js` (החישוב), `js/plans.js` (העורך), `js/plans3d.js` (תלת-ממד), `vendor/` (three.js ו-pdf.js).
ניסיון עם דוגמה מוכנה: `plans.html?demo`

### הגדרת תשלום
1. ב-`js/config.js` תחת `payments` מדביקים קישורי תשלום: PayPal, ביט, פייבוקס, אשראי (Grow וכדומה). כפתור בלי קישור מוצג כ"בקרוב".
2. פותחים את `codes.html` (העמוד לא מקושר מהאתר), מייצרים קודים, שומרים את **הקודים** אצלכם ומדביקים את **הטביעות** ב-`unlockHashes`.
3. לקוח משלם ושולח קוד הזמנה בוואטסאפ, ואתם שולחים לו קוד פתיחה.

> שימו לב: נעילה באתר סטטי היא הגנה בסיסית בלבד, כי מי שמבין בקוד יכול לעקוף אותה. כשיהיו הרבה לקוחות כדאי לעבור לאימות תשלום בשרת (כמו `ai-worker` עם Grow).
> טקסט התקן עצמו לא נכלל באתר, רק ערכים מספריים והפניות לסעיפים.
